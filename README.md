# 🎵 Sonara — Music Player

Sonara is a simple, modern music player built using **HTML, CSS, and JavaScript**. It provides a clean interface for browsing and playing music directly in the browser.

## 🚀 Features

* 🎧 Play and pause songs
* ⏭️ Next and previous song controls
* 📃 Music playlist
* 🎚️ Progress bar for tracking song playback
* 🔊 Volume control
* 🎵 Displays the currently playing song
* 🖼️ Album/song artwork
* 📱 Responsive and user-friendly interface
* 🌐 Runs directly in the browser without a backend

## 🛠️ Technologies Used

* **HTML5** — Structure and layout
* **CSS3** — Styling and responsive design
* **JavaScript** — Music player functionality and DOM interaction

## 📂 Project Structure

```text
Mini-Project/
│
├── assets/          # Images and other visual assets

├── index.html       # Main webpage
├── style.css        # Styling
├── script.js        # Music player functionality
└── README.md        # Project documentation
```

## 💻 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/dev-amanpandey/Mini-Project.git
```

### 2. Open the project

Navigate to the project directory:

```bash
cd Mini-Project
```

### 3. Run the project

Since Sonara is a static website, no package installation or build process is required.

Simply open:

```text
index.html
```

in your browser.

Alternatively, you can use the **Live Server** extension in VS Code for a better development experience.

## 🌐 Deployment

Sonara can be deployed easily as a **Static Site** on platforms such as Render.

For Render, use:

```text
Root Directory:    [leave empty]
Build Command:     [leave empty]
Publish Directory:  .
```

No `npm install` or `npm start` command is required because the project does not use Node.js or a package manager.
